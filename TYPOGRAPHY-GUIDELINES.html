🔤 1. Font Stack & System Fonts

Uses system font stack for optimal performance, fast loading, and native appearance across all platforms.

font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif;

Font Stack Breakdown

Font Platform Why
-apple-system macOS, iOS San Francisco — Apple's native system font
BlinkMacSystemFont Safari (older Mac) Fallback for older Safari on macOS
Segoe UI Windows Windows default system font
Roboto Android Android native font
Helvetica Neue Older systems Fallback for legacy devices
Arial, sans-serif Universal Final fallback for any browser
✅ Benefits: No font files to download (instant loading), native look on every platform, excellent readability, best performance

📏 3. Line Height & Spacing Rules

Line height (leading) affects readability and visual rhythm. Different text sizes have different optimal line heights.

Line Height by Tier

Tier Font Size Line Height Ratio Why
Tiny Badge 10–11px 1.2 12–13px Tight for compact display
Field Label 11.5px 1.4 16px Slightly loose for clickability
Metadata 12px 1.5 18px Comfortable for secondary text
Section Header 12px 1.5 18px Same as Metadata
Body / Value 14px 1.6 22px Comfortable for reading
Buttons & Tabs 14px 1.4 19px Compact for button consistency
Page Hero 20px 1.2 24px Tight for prominent display

Letter Spacing (Tracking)

Normal 0em (default)
Body text, values, headings
Wide 0.05em
UPPERCASE labels and section headers
💡 Why 0.05em for uppercase? Uppercase letters are dense and harder to read. Extra letter spacing improves legibility and creates visual separation. Always add letter-spacing to uppercase text.

📱 5. Responsive Typography — Mobile vs Desktop

On mobile, some font sizes scale down to maintain readability within smaller viewports.

Tier Desktop Mobile (<640px) Reason for Change
Tiny Badge 10–11px 10–11px No change — already minimal
Field Label 11.5px 11.5px No change — labels need to stay readable
Metadata 12px 12px No change
Section Header 12px 12px No change
Body / Value 14px 14px No change — primary content stays consistent
Buttons & Tabs 14px 14px No change — touch targets need readable text
Page Hero 20px 18px Slightly smaller to fit smaller viewport
⚠️ Mobile Typography Principle: Never make text smaller than 14px on mobile — it becomes hard to read. The minimum readable font size on mobile is 14px for body text. Button text must also be 14px+ for touch accessibility.

CSS Media Query Example

/* Desktop — default */ h1 { font-size: 20px; font-weight: 800; } /* Mobile — smaller */ @media (max-width: 640px) { h1 { font-size: 18px; } } /* Tablet — medium */ @media (max-width: 1024px) { h1 { font-size: 20px; /* Keep same as desktop */ } }

🌙 6. Dark Mode Typography Specifications

Font sizes and weights remain the same in dark mode, but text colors change to maintain contrast. Font rendering may appear slightly different due to anti-aliasing.

Text Color Changes — Light → Dark Mode

Text Type Light Mode Color Dark Mode Color Contrast Ratio (Dark Mode)
Primary Text (Values, Headings) #0C2472 (Navy) #D4D4D8 (Light Gray) 12.8:1 (AAA)
Secondary Text (Labels) #334155 (Slate-700) #71717A (Medium Gray) 4.5:1 (AA)
Tertiary Text (Hints, Metadata) #94A3B8 (Slate-400) #9CA3AF (Light Gray) 4.5:1 (AA)
Hero Text (Page Titles) #0C2472 (Navy) #F4F4F5 (Almost White) 15.0:1 (AAA)

❌ 7. Common Typography Mistakes & How to Fix Them

❌ Mistake 1: Inconsistent Font Sizes

Problem: Similar elements have slightly different sizes (e.g., one button is 13px, another is 14px)

Why it's wrong: Breaks visual consistency and signals hierarchy where there is none

Fix: Use exact pixel values from typography tiers. Measure with getComputedStyle() to verify

❌ Mistake 2: No Letter Spacing on Uppercase

Problem: Uppercase field labels are tightly packed and hard to read

Why it's wrong: Uppercase text has poor character spacing; it needs letter-spacing to be readable

Fix: Always add letter-spacing: 0.05em to uppercase text

❌ Mistake 3: Poor Dark Mode Contrast

Problem: Dark mode text is too light or too dark, making it hard to read

Why it's wrong: Breaks WCAG accessibility standards

Fix: Use the specified dark mode text colors. Verify contrast ratio ≥ 4.5:1 with WCAG checker

❌ Mistake 4: Font Weight Confusion

Problem: Using font-weight: 500 for body text instead of 600

Why it's wrong: Medium weight (500) is too light for primary content; Semibold (600) is required

Fix: Follow exact font weights from tiers. Test visual difference between 500 and 600

❌ Mistake 5: Wrong Line Height

Problem: Using line-height: 1.5 for body text (should be 1.6) or 2 for badges

Why it's wrong: Text becomes too loose or too tight, hurting readability and taking up wrong space

Fix: Use exact line heights from the table in Section 3

❌ Mistake 6: Font Size Below 14px on Mobile

Problem: Scaling down body text to 12px on mobile

Why it's wrong: Creates accessibility issues for users with low vision; browsers auto-zoom

Fix: Never go below 14px on mobile. Focus on responsive layout instead

❌ Mistake 7: Using Display Fonts for Body Text

Problem: Mixing system fonts with Google Fonts or other web fonts

Why it's wrong: Adds HTTP requests, slows page load, and breaks system font consistency

Fix: Stick to system font stack. Only custom fonts if absolutely required (and optimize for performance)

✅ 8. Typography Implementation Checklist

When Adding New Text to a Page:

  • ☐ Identify the semantic role: Is this a label, value, heading, timestamp, or button text?
  • ☐ Select the correct tier: Use exact size from Typography Tiers table (don't guess)
  • ☐ Apply font weight: Use exact font-weight from specifications
  • ☐ Set line height: Apply line height from Section 3 table
  • ☐ If uppercase, add letter-spacing: letter-spacing: 0.05em
  • ☐ Choose text color: Primary, Secondary, or Tertiary based on importance
  • ☐ Test in dark mode: Verify colors meet WCAG AA contrast (4.5:1 minimum)
  • ☐ Test on mobile: Verify font size is readable on small screens (≥14px)
  • ☐ Verify with developer tools: Use getComputedStyle() to confirm final rendered values

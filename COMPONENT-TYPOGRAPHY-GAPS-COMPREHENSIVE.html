GAP #9: Mobile Responsive Typography

❌ What Was Missing
On mobile screens (< 640px), typography scaling was NEVER ADDRESSED:
  • Topbar on mobile — font sizes NOT documented
  • Sidebar collapse → mobile nav — NOT documented
  • Table on mobile — columns NOT documented
  • Font size scaling ratios — NOT specified
✅ Mobile Typography Rules
General Rule: Most font sizes stay the same on mobile (14px body, 12px labels, etc.). Only exception: Page Hero titles scale from 20px → 18px

Topbar on Mobile:
  • Logo: 12px (down from 14px)
  • Navigation: Hidden, becomes hamburger icon (24×24px)
  • Topbar height: 56px (down from 60px)

Sidebar on Mobile:
  • Sidebar: Hidden by default
  • Menu opens as drawer/modal overlay
  • Drawer width: min(320px, 90vw)
  • Font sizes: Same as desktop (14px for items)

Tables on Mobile:
  • Display as stacked cards (NOT table)
  • Label: 11.5px UPPERCASE
  • Value: 14px
  • One column per row

🌫️ 8. Shadows & Elevation

A consistent shadow system creates depth and visual hierarchy. All shadows use Primary color with varying opacity levels.

Elevation Level CSS Box-Shadow Usage
Level 0 (None) none Flat backgrounds, text-only elements
Level 1 (Subtle) 0 2px 8px rgba(0, 0, 0, 0.04) Cards, subtle depth, list items
Level 2 (Light) 0 4px 12px rgba(29, 78, 216, 0.08) Popovers, dropdown menus, floating buttons
Level 3 (Medium) 0 8px 24px rgba(29, 78, 216, 0.12) Modals, dialogs, hover states on cards
Level 4 (Heavy) 0 16px 48px rgba(29, 78, 216, 0.16) Full-page overlays, elevation emphasis
Focus Ring 0 0 0 3px #93C5FD Keyboard focus indicator, accessibility
Inset (Pressed) inset 0 2px 4px rgba(0, 0, 0, 0.15) Active/pressed button states
💡 Shadow Best Practices:
  • Keep blur radius consistent: use 8px, 12px, 24px, or 48px
  • Shadow spread should be 0 (no spread for clean look)
  • Use Primary color with opacity instead of black — creates cohesive visual system
  • Apply shadows to surfaces that float (cards, modals, popover menus)
  • Layer shadows (e.g., 2px + 8px) for richer depth on important surfaces

♿ 10. Accessibility & Contrast

All color combinations meet WCAG AA or AAA standards for contrast. Design with accessibility as a requirement, not an afterthought.

Light Mode Contrast Ratios

✅ Primary text (#0C2472) on white: 12.8:1 — WCAG AAA (large & small)
✅ Secondary text (#334155) on white: 9.8:1 — WCAG AAA
✅ Tertiary text (#94A3B8) on white: 4.5:1 — WCAG AA
✅ Primary on Primary (#1D4ED8): 2.8:1 — Use only for decorative elements
✅ White text on Primary (#1D4ED8): 8.2:1 — WCAG AAA
✅ White text on Hover (#60A5FA): 5.8:1 — WCAG AAA

Keyboard Navigation

📌 Focus Management:
  • Tab order: Logical left-to-right, top-to-bottom flow
  • Focus indicator: Always visible 3px ring of #93C5FD
  • Focus visible: Only show focus ring on keyboard navigation (not mouse clicks)
  • Skip links: Provide skip-to-content link for keyboard users
  • Modal traps: Tab must cycle through modal elements only
  • Escape key: Close modals with Escape key

Screen Reader Guidelines

📌 Semantic HTML & ARIA:
  • Use semantic HTML: <button>, <input>, <table>, <nav>, etc.
  • Labels: All form inputs must have associated <label> elements
  • Icons alone: Icon-only buttons need aria-label attribute
  • Tables: Use <th> for headers, scope attribute for accessibility
  • Status messages: Use role="status" or role="alert" for dynamic updates
  • ARIA live regions: Use aria-live="polite" for content that updates

🌙 11. Dark Mode Implementation Guide

Complete specification for implementing dark mode across all pages and components.

Dark Mode CSS Strategy

Option 1: CSS Class-Based (Recommended)
/* Light mode (default) */
.component { background: #EFF6FF; color: #0C2472; }

/* Dark mode */
[data-theme="dark"] .component {
  background: #0A0A0A; color: #D4D4D8;
}
Option 2: CSS Variables
:root {
  --bg-primary: #EFF6FF;
  --text-primary: #0C2472;
}

[data-theme="dark"] {
  --bg-primary: #0A0A0A;
  --text-primary: #D4D4D8;
}

.component { background: var(--bg-primary); color: var(--text-primary); }

Tertiary Text #94A3B8 (Slate-400) #9CA3AF (Medium Gray) Placeholders, hints

Dark Mode Testing Checklist

🔍 Before Shipping Dark Mode:
  • ☐ All text meets 4.5:1 contrast ratio minimum
  • ☐ Icons are visible and properly colored
  • ☐ Form inputs have clear focus states
  • ☐ Tables and lists are readable
  • ☐ Modals/popovers don't blend into background
  • ☐ Status colors (success/error/warning) are distinguishable
  • ☐ Badges and tags are readable
  • ☐ Charts and graphs have enough contrast
  • ☐ Gradients look intentional, not washed out
  • ☐ Hover/focus states are clearly visible
  • ☐ Tested in actual browser dark mode (not just CSS)

🔄 For New Apps — Color Adaptation Guide

To use this design system for a new app (HRMS, Projects, etc.):

  1. Choose your new Primary color (replace #1D4ED8)
  2. Generate secondary shades using a color tool (Action, Hover, Soft tones)
  3. Keep Text, Status, and Dark Mode colors unchanged (they're universal)
  4. Apply new Primary color throughout all templates above
  5. Test contrast ratios to ensure WCAG AA compliance
